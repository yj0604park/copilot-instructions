# Raspberry Pi — Gallery & AI

- **모델**: Raspberry Pi 5 Model B Rev 1.0
- **CPU**: ARM Cortex-A76, 4코어, aarch64
- **메모리**: 8GB
- **OS**: Debian (Linux, aarch64)
- **Tailscale**: raspberrypi.tail591527.ts.net

## Docker
- **런타임**: docker-ce (apt)
